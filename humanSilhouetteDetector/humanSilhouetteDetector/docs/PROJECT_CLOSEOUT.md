# プロジェクト総括 (PROJECT CLOSEOUT)

## 1. 達成事項
ウォーターフォールの全工程（要件定義 → 基本設計 → 詳細設計 → 実装 → テスト → 運用準備）を完了し、
Web カメラ映像から人物の輪郭をリアルタイム認識し、ブラウザへ配信する商用組込可能なアプリケーションを構築した。

顧客指定の品質ライン「人の輪郭まで認識」を、MediaPipe Pose のセグメンテーションマスクによる
輪郭抽出（半透明塗り + 輪郭線）として実装した。

## 2. 顧客要件の充足状況
| 要件 | 状況 |
|---|---|
| ローカルで画像認識 AI、Web カメラで人影認識 | 達成（MediaPipe + OpenCV + Flask） |
| 人の輪郭まで認識（品質ライン） | 達成（セグメンテーション輪郭描画） |
| 商業利用できるよう選定 | 達成（依存はすべて Apache/BSD。AGPL 不採用） |
| 市場でよく使われる言語・モデルで保守容易 | 達成（Python / MediaPipe / Flask） |
| 納期 約 1〜2 ヶ月・ウォーターフォール完遂 | 達成 |
| 将来 VLM 併用へ拡張 | 拡張点を設計・実装（RecognizerBase） |
| 将来サーバ転送・顔保存へ拡張 | 拡張点を設計・実装（OutputHandlerBase） |

## 3. 引き継ぎ・残作業
1. **実機テストの実施**: TEST_PLAN.md に沿って Web カメラ + 実モデルで検証し、結果を記入する。
2. **性能チューニング**: TC-08（目標 10fps）の結果次第で config.py を調整する。
3. **モデル配置**: models/README.md に従い pose_landmarker_lite.task を配置する。
4. **GitHub 反映**: 本一式をリポジトリへコミット（.task はリポジトリに含めない設定済）。

## 4. Phase 2 への申し送り
- VLM 採用時はライセンスの個別精査が必須（R-01）。
- 顔保存・サーバ転送は実装着手前に法務確認をゲートとする（R-02）。
- いずれも既存層を壊さず拡張点に差し込める設計。詳細は OPERATIONS.md 第 6 章。

## 5. 学びの要点（教育まとめ）
- LLM と CV は別領域。要望の言葉ではなく「達成すべきタスク」を見極める。
- OSS は「無料」と「商用組込可」が別。ライセンスはエンジニアの責任範囲。
- 「作らないが、差し込み口だけ用意する」拡張設計（インターフェース駆動）。
- 変更要求は黙って吸収せず変更管理として記録する。
- テストは要件 ID と紐づけ、取りこぼしを防ぐ（トレーサビリティ）。
